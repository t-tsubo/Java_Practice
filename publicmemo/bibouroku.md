## 備忘録
**問題**
VSCodeでテストを実行すると、日本語が文字化けしていた
**詳細**
- フラスコマークからテストを実行すると文字化けが起こる
- 出力結果はデバッグコンソールに表示される
- 出力をターミナルに変更しようとしてもうまくいかない(そもそも出力されない)
- Javaプログラムの出力はUTF-8になっていた
- Gradleコマンドで実行すると文字化けは起こらない
**原因**
`Test Runner for Java`という拡張機能のテスト用JVM(Java仮想マシン)の文字コード指定が足りなくて、そこで文字化けを起こしていた
**解決方法**
`settings.json`に以下のコードを記述した
```json
    // Test Runner for Javaという拡張機能の設定
    "java.test.config": {
        // 設定の名前 今回は文字化けを解決したいのでUTF-8とした
        "name": "UTF-8",
        // VM(仮想マシン、JVM)に対して渡す設定内容(引数)
        "vmArgs": [
            // Javaのデフォルト文字コードをUTF-8に指定
            "-Dfile.encoding=UTF-8",
            // 標準出力の文字コードをUTF-8に指定
            "-Dstdout.encoding=UTF-8",
            // 標準エラー出力の文字コードをUTF-8に指定
            "-Dstderr.encoding=UTF-8"
        ],
        // テストプロセスに渡す環境変数
        // 今回は必要なさそうだった
        "env": {
            "LANG": "ja_JP.UTF-8",
            "LC_ALL": "ja_JP.UTF-8"
        }
    },
    // "UTF-8"という設定ファイルを適用する
    "java.test.defaultConfig": "UTF-8",
```
**メモ**
今回の設定はフラスコマーク(`Test Runner for Java`)からテストを実行するときにしか効果がない点に注意
